# Bob sees Iosevka labels

## User Story

Bob opens dre, draws a box with a label, and sees the label rendered in Iosevka Term Regular in the terminal, so that his diagram immediately looks like a dre diagram.

## Acceptance Criteria

- The Iosevka Term Regular font file is bundled with dre (no separate install required by the user).
- Box labels in the terminal render using Iosevka Term Regular.
- Arrow labels in the terminal render using Iosevka Term Regular.
