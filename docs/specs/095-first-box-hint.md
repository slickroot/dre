# First box hint

## User Story

As a first-time dre user, I want to see a hint on the empty canvas telling me how to add my first box, so that I know how to get started without reading documentation.

## Acceptance Criteria

- When `dre` opens with no boxes on the canvas, light gray hint text reading "press b to add a box" is shown where the first box would appear.
- As soon as a box is added, the hint disappears and never reappears for that session.
