# 065 - README explains what dre is and how to install it

## Story

Bob visits the `dre` GitHub repo. He finds a README that tells him what `dre`
is and how to install it.

## Acceptance Criteria

- The `dre` GitHub repo's front page shows a README.
- It opens with this description:
  > **dre** is a keyboard-driven diagram editor that runs in your terminal.
  > Build a tree of boxes with a few keystrokes, style them, and save it to a
  > `.dre` file.
- It lists the requirements:
  - an Apple Silicon Mac
  - tested terminals: WezTerm works, Terminal.app doesn't
- It shows the install command:
  `curl -fsSL https://raw.githubusercontent.com/slickroot/dre/main/install.sh | bash`
- The install section ends at that command.
